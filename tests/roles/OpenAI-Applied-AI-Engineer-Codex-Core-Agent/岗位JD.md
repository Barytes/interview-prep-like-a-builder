团队：Codex Core Agent。地点：San Francisco、New York City、Seattle、London。

## 团队与岗位

团队负责 Codex 的核心执行、模型和工具接口、共享基础设施及使用反馈；关注 token、时延、可靠性、成本和容量。岗位与研究、基础设施、产品协作，将模型能力转为真实软件工程任务的解决率、实用性和经济价值。

## 工作职责

1. 设计、迭代真实编码任务与长流程中的 agent 行为。
2. 与研究团队开发、运行评估，检查性能、回归、失败模式和边界情况。
3. 通过提示、工具策略、上下文构建及面向模型的实验改善表现。
4. 分析生产失败，提高稳健性和可靠性。
5. 建设反馈与数据系统，将真实任务数据用于评估和研究。
6. 与产品团队设计用户体验及 agent 所依赖的接口。
7. 定义复杂任务端到端完成的质量标准。

## 候选人要求

- 有 ML 或 LLM 产品构建、交付经验。
- Python 能力强，熟悉现代 ML 工具。
- 有模型评估、微调或提示设计经验。
- 关注系统和用户结果。
- 喜欢排查真实失败并推动改进。
- 希望将研究与模型潜力转为用户可用的系统。

## 加分项

- Agent 框架或工具调用系统经验。
- 代码生成模型或开发者工具研究经验。
- 大型复杂数据集或生产日志处理经验。
