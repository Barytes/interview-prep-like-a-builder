# 记下反馈

按 [教学反馈格式](references/records.md) 记录用户的明确评价与必要情境。仅表达知识缺口时交回教学 skill 继续解释，学习表现由 `track-progress` 保存。

查找相关改进项：相同问题追加依据，新问题单独记录；有效做法和偏好也可以提出保留建议。原话、建议和实际改动分别写明，适用情境以已知反馈为依据。

已有会话归档时引用具体事件；尚未归档时保存原话、会话出处和时间。后续取得归档后可补充引用。反馈记录不触发 `save-trace`。

已落实到技能的改进项标为“待试用”；用户在后续试用中明确认可效果后标为“已确认”，附依据。问题再次出现时转回“待处理”。

简短告知记下了什么，再继续当前任务。当前讲法随反馈调整；用户要求修改技能时按开发职责处理。
