# 教学反馈格式

## 存放与复用

本轮教学反馈保存在学习记录目录的 `FEEDBACK.md`，目录定位见 [共同存放约定](../../track-progress/references/state.md#放在哪里)。继续准备时由 `track-progress` 读取，教学 skill 据此调整当前安排。

skill 开发的公共改进项沿用工作目录约定，未指定时使用 `docs/feedback.md`。来自实际试用的改进项引用本轮 `FEEDBACK.md` 的具体条目，原话与本轮处理历史保留在原处；同一改进项可以关联多个岗位。开发讨论直接记在公共改进项中，不另建一轮岗位准备。

## 条目

每份文件内用递增编号标识条目，例如 `F001`；跨文件引用时带上文件路径和条目锚点。按实际情况记录：

- **问题或保留建议**：简短描述，关联技能与适用情境。
- **用户评价与依据**：已有归档时引用 `conversation.md#事件ID` 或 trace 事件 ID；尚未归档时保存原话、必要情境、会话 ID 或标题与时间。
- **准备尝试**：建议如何调整教学方法。
- **处理进展**：本轮已作或待作的调整；公共改进项使用待处理、待试用或已确认。
- **改动与后续反馈**：实际修改及版本、后续用户评价和出处。

来自开发讨论的评价注明“开发讨论”，与实际使用后的评价分清。

后续取得归档时补上原话的事件引用，保留人工整理的评价与处理历史。trace 中包含评价原话，并不自动产生改进项；记录事实和整理评价分别进行。

开发时根据反馈选择修改内容；日常教学结合本轮反馈、用户最新指示与共同教学约定继续当前任务。
