# 教学反馈格式

全局教学反馈沿用工作目录的约定，未指定时使用 `docs/feedback.md`。它保存用户评价和改进项；会话记录由显式调用的 `save-trace` 归档。

每个改进项用递增编号标识，例如 `F001`，包含：

- **问题或保留建议**：简短描述，关联技能与适用情境。
- **用户评价与依据**：已有归档时引用 `conversation.md#事件ID` 或 trace 事件 ID；尚未归档时保存原话、必要情境、会话 ID 或标题与时间。
- **准备尝试**：建议如何调整教学方法。
- **处理进展**：待处理、待试用或已确认。
- **改动与后续反馈**：实际修改及版本、后续用户评价和出处。

同一改进项可关联多个岗位。来自开发讨论的评价注明“开发讨论”，与实际使用后的评价分清。

后续取得归档时补上原话的事件引用，保留人工整理的评价与处理历史。trace 中包含评价原话，并不自动产生改进项；记录事实和整理评价分别进行。

开发时根据反馈选择修改内容，日常教学执行当前技能中的共同约定与流程。
