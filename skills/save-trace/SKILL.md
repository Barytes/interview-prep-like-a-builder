# 保存本次会话

仅在用户显式调用本技能时归档。读取 [归档说明](references/archive.md)，确认目标岗位和当前会话 ID，找到对应的 Codex JSONL 日志。

运行 [归档脚本](scripts/save_trace.py)，传入日志、技能仓库、岗位目录和任务说明。已知的使用技能和学习记录可一并提供；模型、harness 和逐轮配置从日志取得。

检查导出的运行信息和截止位置，告知归档路径与缺失内容。再次调用时使用相同会话 ID，更新同一个 run。

本技能保存会话记录，不生成教学反馈、评分或改进项。评价原话作为对话内容保留，教学反馈由 `note-feedback` 单独处理。
