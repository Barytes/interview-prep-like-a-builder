# 帮我准备面试

根据用户输入和已有记录决定接下来做什么，让对应 skill 继续执行。

明确要求修改技能或项目文档时，按工作目录的 `AGENTS.md` 进入开发职责。其余情况沿用已知目标岗位；缺少会影响当前任务的信息时再询问。

开始或继续岗位准备，调用 `track-progress` 读取学习记录和共同教学约定。把学习记录目录及当前任务传给所选 skill：

| 当前需要 | 调用 |
| --- | --- |
| 认识岗位、学习知识、练习或补课 | `teach-me` |
| 选择岗位项目、确定需求、实现或验收 | `build-with-me` |
| 继续上次任务 | 根据学习记录中的当前任务选择上述 skill |
| 明确评价教学方式 | `note-feedback` 记录教学反馈，再继续当前任务 |

做项目时的小问题就地解释；需要展开教学时切换到 `teach-me`，记录学完后要返回的项目任务。用户继续当前任务时沿用已选 skill；方向改变时再选择。
