# 记录目标和进度

读取 [共同教学约定](references/teaching.md) 和 [学习记录格式](references/state.md)，已有且未变化的内容直接复用。

## 读取

优先沿用传入的学习记录目录，其次按用户指定位置或工作目录索引查找。存在多个候选且无法判断时，确认要继续哪一轮岗位准备。

读取准备目标、岗位与项目说明、学习表现与进度，以及已有的本轮教学反馈。结合用户最新指示，返回目录绝对路径、当前任务、下一步、适用的教学反馈和共同教学约定。正式开始一轮岗位准备时建立记录；用户要求重新开始时按其指定范围处理。

## 保存

准备目标、学习表现、项目结果或安排变化时，读取最新文件，更新相应部分。教学判断和下一步由教学 skill 提供，连同具体依据保存。

切换技能时保存当前任务、切换原因及返回任务，传递同一个学习记录目录。
